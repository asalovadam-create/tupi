# P2P Guardian (прототип)
Стек: Python (Flask) + HTML + CSS + JS, без внешних зависимостей на фронтенде.
Запуск: `pip install -r requirements.txt && python app.py`, затем http://127.0.0.1:5000
Данные лежат в data.json (создаётся сам). Слой хранения изолирован в store.py: при переезде на сервер замените класс Store на PostgreSQL.
Сделано: карты банков (3D-наклон), поступления и расходы, защита от дублей, отправители по псевдонимам, фильтры периодов, прозрачная оценка риска с объяснениями, журнал действий, светлая и тёмная темы, отдельная мобильная компоновка.
Дальше: авторизация и 2FA, AI Guardian, новости, документы, уведомления, экспорт Excel и PDF.

## Деплой на Render (демо)
1. Загрузите папку в репозиторий GitHub.
2. Render: New → Blueprint (подхватит render.yaml) или Web Service: Build `pip install -r requirements.txt`, Start `gunicorn app:app --workers 1 --threads 4 --bind 0.0.0.0:$PORT`.
Важно: workers=1, иначе JSON-файл будет конфликтовать. На бесплатном тарифе данные стираются при перезапуске. Реальные данные не вводить: входа в аккаунт пока нет.
